# Kumar Anurag — Portfolio Website

Responsive premium-light glassmorphism portfolio built with HTML, CSS and JavaScript.

## Run it
1. Keep the folder structure and filenames as shown below.
2. Open `index.html` or use VS Code Live Server for local testing.
3. To select a logo for the inner hero circle, click the small `+` on the circle. This is a local preview; it does not upload/save the logo to a server. To make it permanent for visitors, save your logo as `images/logo.png` and replace the preview-only control with an `<img src="images/logo.png">`.

## Convert JPG to PNG
The website references are now `.png`. Renaming `.jpg` to `.png` is not a real conversion. Convert the files using an image editor or a batch converter, then keep the exact same base filename with `.png`. Videos should remain MP4.
